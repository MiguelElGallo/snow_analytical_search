# Snowflake Analytical Search

Native document parsing, search and evidence-based questions over the Azure sample corpus.

You need a **Snowflake account**; a trial account can be used. For self-service
trials, add a credit card to enable AI services. **Adding the card alone does not
start paid billing:** AI and other usage consume the free trial allowance.
Upgrading to a paid account is a separate action and can lead to charges.
See [Snowflake's official trial documentation](https://docs.snowflake.com/en/user-guide/admin-trial-account).
**Always check that these terms still apply before adding a card or running the demo.**
